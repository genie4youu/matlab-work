# sessions — 날짜별 작업 폴더

분석할 모델과 데이터를 **날짜 폴더 하나에 담아** 넣는다. 그 날 볼 것만 여기 있으면 된다.

```
sessions\
├── 2026-08-05\
│   ├── models\      .slx .mdl
│   ├── data\        .mat .csv 등 입력 데이터
│   └── out\         분석 결과·생성물
└── 2026-08-12\
```

폴더 안 구성은 자유다. `models\` `data\` 만 지키면 찾기 쉽다.

---

## 여는 방법

MATLAB 명령창에서:

```matlab
session('2026-08-05')
```

- 그 폴더로 이동하고 **그 날짜만** 경로에 올린다
- 이전에 열었던 날짜는 자동으로 경로에서 내려간다
- 안에 있는 모델 목록을 바로 찍어준다

날짜가 기억 안 나면 인자 없이:

```matlab
session
```

---

## 🔴 왜 `sessions\` 는 자동 등록에서 빠져 있나

`startup.m` 은 `matlab-work` 아래를 전부 경로에 올리지만 **`sessions\` 만 제외**한다.

날짜 폴더를 전부 올리면, **같은 이름의 모델이 여러 날짜에 있을 때 MATLAB 이 경로 순서대로 아무거나 집는다.** 경고가 안 나서 알아채기 어렵다 — *"고쳤는데 안 바뀐다"* 의 전형적인 원인이다.

그래서 한 번에 하나만 올린다.

---

## 폴더 이름 규칙

| | |
| --- | --- |
| 날짜 폴더 | `YYYY-MM-DD` (ISO). 예: `2026-08-05` |
| 그 안 | **ASCII 소문자 + 하이픈.** 한글·공백 금지 |

한글이나 공백이 경로에 들어가면 **코드 생성이 깨진다.** 이 폴더 전체를 볼트 밖에 둔 이유가 그것이다.

> ⚠️ 모델 **파일 이름**은 MATLAB 식별자 규칙을 따라야 한다 — 영문으로 시작, 하이픈·공백 불가 (`supervisor_v2.slx` ○ / `supervisor-v2.slx` ✗).
> 폴더 이름은 하이픈을 써도 된다.

> ⚠️ 회사 Fasoo DRM 이 걸린 파일은 MATLAB 도 Claude 도 못 연다 (매직바이트 `9b 20 44 52`).
> 복사해 왔는데 안 열리면 DRM 부터 확인한다.
